# Data descriptors

A typeset data descriptor (PDF) for each archived dataset of the Ukrainian
Frequency study: abstract, data records with every file's checksum, methods,
integrity and verification, scope, known limitations, usage notes, data and
code availability, sources, versions, and how to cite (with BibTeX).

| Dataset | Version | DOI | PDF |
|---|---|---|---|
| Ukrainian Frequency: a lemma-based, coverage-graded open frequency list for modern Ukrainian (top 12,000, over UberText 2.0) | v0.2.0 | https://doi.org/10.5281/zenodo.22949965 | [frequency-v0.2.0.pdf](frequency-v0.2.0.pdf) |
| Ukrainian Frequency: the PULS CEFR overlay (validated A1 to C1 levels joined onto the top-12,000 list) | 2026-09-13 | https://doi.org/10.5281/zenodo.24388001 | [validated-cefr-2026-09-13.pdf](validated-cefr-2026-09-13.pdf) |
| Ukrainian Frequency: word stress for every lemma of the top-12,000 list (over ukrainian-word-stress, en.wiktionary and uk.wiktionary) | v1.0.2 | https://doi.org/10.5281/zenodo.24237775 | [stress-v1.0.2.pdf](stress-v1.0.2.pdf) |
| Ukrainian Frequency: the B1 enrichment tables (aspect relations, case government, collocations) | 2026-09-13 | https://doi.org/10.5281/zenodo.24388340 | [b1-enrichment-2026-09-13.pdf](b1-enrichment-2026-09-13.pdf) |

Each is generated from the dataset's datasheet, the DOI registry and the
released files, so it says nothing its deposit does not. `manifest.json`
records the SHA-256 of the HTML each PDF was printed from. A dataset whose
next version is not yet minted gets its descriptor when it is.
